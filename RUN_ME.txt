=========================================================
 DS2 -> .ipa : ЧТО ВСТАВИТЬ В cmd.exe (копируй построчно)
=========================================================

Ошибка была из-за того, что "# один раз" в cmd.exe НЕ комментарий,
а три аргумента (отсюда "accepts 0 arg(s), received 3"), и bash
в обычной консоли не на PATH. Всё уже переделано под cmd.exe.

---------------------------------------------------------
ШАГ 1 (один раз, авторизация GitHub; откроется браузер):

gh auth login --web --git-protocol https

  !!! НИКАКОГО текста после команды, без # и комментариев !!!

---------------------------------------------------------
ШАГ 2 (всё остальное одной командой, из ЛЮБОЙ папки):

C:\docs\darksouls2\ios_port\ci\launch.bat

---------------------------------------------------------
НЕОБЯЗАТЕЛЬНО (подпись своим сертификатом, перед шагом 2):

set DS2_P12=C:\path\cert.p12
set DS2_P12_PASSWORD=yourpassword
set DS2_MOBILEPROVISION=C:\path\profile.mobileprovision

---------------------------------------------------------
АЛЬТЕРНАТИВА, если хочешь через Git Bash:

"C:\Program Files\Git\bin\bash.exe" -lc "cd /c/docs/darksouls2 && bash ios_port/ci/launch.sh"

---------------------------------------------------------
ЧТО ДЕЛАЕТ launch.bat:
  [1/6] создаёт ПРИВАТНЫЙ репозиторий и пушит ds2-ios-build/
  [2/6] заливает Default.xex (21 МБ) + ds2_shaders.spvz (501 МБ)
        в приватный релиз (в git эти файлы НЕ попадают)
  [3/6] ставит секреты подписи, если заданы переменные выше
  [4/6] запускает ds2-full.yml и ждёт
  [5/6] скачивает .ipa в C:\docs\darksouls2\ios_port\out\ci\
  [6/6] печатает команду для лога, если что-то упало

Первый прогон скорее всего упрётся в линковку SDL3-iOS/MoltenVK —
это ожидаемо. Скинь сюда вывод:
  gh run view <run-id> --log-failed
